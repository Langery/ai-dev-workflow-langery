# commit message 模板（配合 commitizen / 手动使用）
# 用法：git config --local commit.template .gitmessage
# Go 项目推荐用 commitizen-go 或直接按格式手写
#
# 格式：<type>(<scope>): <subject>
#
# ============================================================

<type>(<scope>): <subject>

# <body> —— 说明改了什么、为什么改，不超过 72 字符/行
#
# <footer>
# - BREAKING CHANGE: 有破坏性变更必须写
# - Co-Authored-By: Claude <noreply@anthropic.com>  # AI 辅助时加

# ============================================================
# type 白名单（Conventional Commits）：
#   feat      新功能
#   fix       bug 修复
#   docs      文档变更
#   style     格式调整（不改逻辑）
#   refactor  重构（不修 bug 不加功能）
#   test      测试相关
#   chore     构建/工具/依赖
#   perf      性能优化
#   ci        CI 配置
#   build     构建系统
# ============================================================
# scope 白名单（按 Go 分层）：
#   handler    HTTP handler
#   service    业务逻辑
#   repo       数据访问
#   model      数据模型
#   middleware 中间件
#   auth       认证授权
#   config     配置
#   db         数据库/迁移
#   test       测试
#   ci         CI/CD
# ============================================================
# 提交前自检：
#   [ ] golangci-lint run 全过
#   [ ] go test ./... 全过
#   [ ] go mod tidy 后无 diff
#   [ ] error 全部处理（没有 _ = err）
# ============================================================
